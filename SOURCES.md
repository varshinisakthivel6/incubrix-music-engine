# Sources, Models, Libraries and Rights

## Active music provider
- `procedural` (`app/providers/procedural_provider.py`): locally generates instrumental music stems. This is the provider currently selected in `.env`.
- The procedural generator is not the same as a pretrained AI music model. Do not claim that its output is generated by a pretrained AI model.

## Tested local model
- Stable Audio Open Small was tested locally using the Stable Audio CLI.
- A sample output is saved as `stable_audio_test.wav`.
- The local CLI test does not mean the model is integrated into the main application's active provider.
- Verify the exact model licence and permitted uses before making commercial-use claims.

## Other providers
- `mock_provider.py`: test provider for pipeline/API verification; do not present its synthetic test output as publishable AI-generated music.
- `soundverse_provider.py`: optional provider implementation; verify credentials, API access, terms and functionality before use.
- `stable_audio_provider.py`: optional integration; the main application is not currently configured to use it.
